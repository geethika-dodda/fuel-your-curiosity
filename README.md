# 🔍 Fuel Your Curiosity

**Fuel Your Curiosity** is a web project built around a simple idea: there is always something interesting to learn.

The website presents everyday technologies and concepts in a simple, engaging way, with the goal of making people curious about **how the things we use every day actually work**.

## 🌐 Live Website

👉 [Fuel Your Curiosity](https://fuel-your-curiosity-312ae3pjr-geethikadodda-5409.vercel.app)

## 💡 What is this project?

We use technologies like Wi-Fi, GPS and QR codes almost every day without really thinking about what happens behind the scenes.

This website is my attempt to turn that curiosity into an interactive learning experience.

Instead of just giving definitions, the articles are designed to explain the ideas behind these technologies in a way that is easier to explore and understand.

## ✨ Features

* 🔍 Explore different technology-based topics
* 📖 Dedicated pages for individual topics
* 💡 Simple explanations of how everyday technologies work
* 🧠 "Dive Deeper" sections for exploring concepts further
* 🎨 Interactive and modern user interface
* 📱 Responsive design for different screen sizes
* 🚀 Deployed and accessible online

## 📚 Topics

Some of the topics currently explored include:

* 📶 **Wi-Fi** — How wireless communication works
* 📍 **GPS** — How your location can be determined using satellites
* 📱 **QR Codes** — How those little black-and-white patterns store information

More topics can be added as the project grows.

## 🧩 How I Built It

I built this project while learning and experimenting with web development.

I used AI tools, including **ChatGPT**, to help me understand concepts, generate parts of the code, and troubleshoot errors. However, I didn't just copy and paste a finished project.

I worked through the structure of the application, understood how the different files and components connected, modified the generated code, fixed errors, worked with routing, and handled the deployment process myself.

One of the main things I learned from this project was that building a website is more than just writing code. It involves understanding how **UI/UX, components, routing, GitHub, deployment, and debugging** all fit together.

## 🚀 Running the Project Locally

If you want to run the project on your own computer:

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 2. Open the project folder

```bash
cd fuel-your-curiosity
```

### 3. Install the dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open it in your browser

```text
http://localhost:3000
```
